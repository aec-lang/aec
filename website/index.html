AEC — Agent Easy Creator

A language for agents,
with the window in the same file.

Write the logic, the permissions, and the interface in one .aec file. It is type-checked before it runs, then rendered as a native window or a terminal UI.

agent Greeting

ui Main = Screen "Greeting" {
    @name: string = ""
    Column {
        Input placeholder: "Name" bind value to name
        Text "Hello {name}"
    }
}

🧠

Agents, not scripts

Modules, closures, Result/? error propagation, and nominal struct/enum with pattern matching. A type checker that actually gates execution.

🪟

A real window

Native egui rendering with reactive rebuilds, reusable components, themes, and correct right-to-left Persian layout. The same UI also runs in your terminal.

🔒

Default-deny

Declare permissions and undeclared network, filesystem, system, and model access is denied. For untrusted input, wrap the run in an OS sandbox.

📦

Signed packages

apm resolves dependencies and publishes to an immutable registry bound by SHA-256 metadata and detached Ed25519 signatures.

Install

curl -fsSL https://raw.githubusercontent.com/aec-lang/aec/main/scripts/install-release.sh | bash

Verifies the archive against the published SHA256SUMS, then installs aec and apm into $HOME/.local/bin.

curl -fLO https://github.com/aec-lang/aec/releases/latest/download/aec-windows-x86_64.zip
sha256sum -c SHA256SUMS

Download both files, then check the archive against SHA256SUMS.

git clone https://github.com/aec-lang/aec.git
cd aec
PREFIX="$HOME/.local" ./scripts/install.sh

Requires Rust 1.75+. Linux native UI builds also need the GTK, XCB, and OpenSSL development packages.
